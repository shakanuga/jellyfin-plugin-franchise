Mitgelieferte Sammlungen

Unter-Sammlungen (z. B. die MCU-Phasen) werden automatisch mit angelegt, wenn die übergeordnete Sammlung aktiv ist.

Einstellungen

Benutzer, die eigene Watch-Order-Playlists bekommen:
Jeder ausgewählte Benutzer bekommt seine eigene Kopie. Keiner ausgewählt = nur der erste Benutzer.
Statt der Jellyfin-Collage: Hintergrundbild eines passenden Titels mit Name und Jahren. Eigene Bilder (Datei/URL) haben Vorrang.
Standardmäßig aus – Gesehenes bekommt nur einen Haken. An: oben steht immer das Nächste, als ungesehen markieren bringt es zurück.
Neue Filme/Folgen landen dann von selbst in den richtigen Sammlungen.
Wenn keine IMDb/TMDb/TVDB-ID passt, wird über Originaltitel und Erscheinungsjahr (±1) gesucht.
Normalerweise wird eine Sammlung erst angelegt, wenn mindestens ein Titel davon in der Bibliothek ist.

Namens-Zuordnungen für automatische Listen

Nur nötig, wenn eine Serie aus der MCU-Liste nicht erkannt wird (steht im Bericht). Eine pro Zeile: Name in der Liste = Name in Jellyfin

Eigene Sammlungen (JSON)

Ein Objekt oder ein Array von Definitionen. Gleiche id wie eine mitgelieferte Sammlung = überschreibt sie. Alternativ kannst du *.json-Dateien in config/plugins/configurations/FranchiseCollections/ legen. Bilder: <id>-poster.jpg und <id>-backdrop.jpg in denselben Ordner.
